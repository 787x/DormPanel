# PR57 追加修复：预检生命周期与 Android 目录

本修复基于 PR57 `d0d3aeb`，更新原分支，不改 DPV3/3、课程/因果规则、Room schema、正式版本或 Release。

## 有效任务与保留策略

- 预检自创建起 **24 小时固定到期**，失败、继续和重复请求均不续期。Android 旧任务缺少创建时间时，首次管理给予完整 24 小时兼容期。正常 `VALIDATING/READY` 不因名额紧张而被删除；版本、前沿变化导致无法再确认的任务按 `STALE` 处理。
- fnOS 每身份最多 8 个有效预检、工作区最多 64 个；Android 同一 Store 最多 8 个。每个 Store/Workspace 同时最多保留 128 个有效/清理中的任务记录，避免清理进度落后时无限新增。达到有效上限需继续、取消或等待固定到期；达到材料上限需继续有界清理，不能绕过未知材料。
- 取消、失效、到期及已完成任务不再占有效名额。创建、取消和 Android 打开任务管理时按需清理，不新增定时器或常驻轮询。
- fnOS 默认 read 可取消**本身份**的私有预检，不能取消其他用户/工作区任务。最终切换仍须 admin，CLI/MCP 仍须独立网页批准。有效批准和 Agent 未决确认意图保护其任务材料；未决意图沿既有 24 小时操作 ID 恢复窗口保留。同步、Catalog 配置、维护、迁移及备份恢复互斥期间不清理。
- 最近 32 个已结束任务保存无凭据状态记录；旧 Token 不再保留该记录时明确报“已回收或不存在”，不与新任务复用。已提交决定另保留必要的最小确认回执，继续验证原用户/工作区归属及 datasetId，重复确认不创建连接、不改绑定。

## 材料回收与中断

先在 SQLite/Room 持久标记 `CLEANING` 和原终态、移除候选重复凭据，再逐批回收。`CLEANING` 从不重新作为可继续的 `READY`；中断后继续同一清理阶段。

fnOS 每轮至多处理 256 个候选验证行；只删除精确 `endpoint:<token>:` 前缀下、已知且校验通过的验证命名空间，不删除 RAW 表或任何共享缓存。未知命名空间、RAW 引用或归属异常停止本批事务。PR56 整理和备份对 `CLEANING` 候选保留逐行校验与快照引用保护，允许该候选的身份/图索引已经部分清理，不把它误判为活动历史损坏。

Android 每轮至多处理两个候选，图验证按 128 行分页，旧缓存目录按 64 个条目推进。要求已有私有格式、已有 owner lock、唯一已知元数据表；不会为清理初始化缺失或未知数据库。图验证完成后持久进入 `FILES`，关闭候选连接，再逐文件删除确切的候选 SQLite、WAL、SHM 和 owner lock。未知文件/链接/格式停止清理，不递归猜测删除。

**受保护材料仍保留：** fnOS 的共享对象缓存、RAW、witness/pin、归档与恢复依赖不动。Android 新预检直接复用单 Store 的共享不可变缓存，避免每次取消留下新缓存副本；旧版已创建的独立候选缓存不删除，验证路径、内容及 witness 后在 `endpointProtectedCache` 登记位置和逻辑字节数，保留原路径，只移除其验证数据库。这些旧缓存、必要确认回执和共享缓存不是有效任务名额，也没有自动物理 GC。SQLite 删除行后以可复用页处理，不承诺文件立即缩小。

## Android 目录行为

账号基础 URL 来自当前 v3 独立账号；表单共享目录默认值来自活动 v3 Room 绑定的 `folder`，不读取全局导入目录或外层旧输入框。无法读取活动绑定/账号时明确停止，不猜测服务根。

修改服务器地址本身不改共享目录。用户可明确点击“按新服务器地址保留当前共享目录路径”，只替换 scheme/host/port，保留原完整路径；用户仍可编辑最终完整 URL。证书/密码/账号修改无需重新寻找原目录。

## 验收范围

实际命令、输出、源码指纹和设备结果见 [追加结构化记录](evidence/pr57/lifecycle/verification.json)。2026-10-26 收尾：NAS 官方包用户相关回归 97/97；最终端点与 CLI/MCP 定向 20/20；JVM 6/6。两台设备各 3 项通过、1 项 NAS probe 缺省跳过；最终材料检查后各追加 1 项 70 次生命周期实机测试，以及各 1 项最终 UI/失败安全测试通过。各轮日志分别保留，不把早先回归冒充后续源码重新全量实测。

- fnOS：同工作区连续 70 次创建/取消后再次验证、确认、回收和重复确认；有效任务/配额、固定到期、网络失败、其他用户拒绝、有效独立批准及未决确认意图保护、未知命名空间拒绝、清理中断、Catalog 重开、半清理候选的 PR56 备份及维护验证。
- Android JVM：70 次回收、旧缓存保留及计数、逐文件清理中断重开、有效任务和旧任务兼容期、完成回执去重、未知文件/数据库拒绝、目录 origin 替换规则。
- Phone 与 X08E 独立测试包：Room 中连续 70 次取消后验证/确认/重开/重复确认、Writer/本地/回执与全局账号不变；正式表单默认非根目录、修改服务器不暗改目录、显式建议保留路径；账号 baseUrl 为根但实际预检访问 `/new/` 的网络 oracle；原确认提交前后中断及过期编辑回归。
- 本轮不再执行 NAS 直连完整互通（该可选测试无 probe 参数而跳过），不安装日用 APK/FPK，不做真实断电、增长或 soak。本轮仅安装独立核心测试 APK。
