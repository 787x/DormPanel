# DormPanel Schedule Manager v0.8.3（预发布）

在 fnOS 网页中创建、编辑和删除 Todo 清单、任务及纯文本备忘，任务可标记完成或恢复为未完成。共享工作区使用 **DPV3/4**，可与支持该格式的 X08E 和 Phone v0.1.13 同步。课程管理、工作区与连接、版本历史、加密备份和目录授权仍在原有入口。

管理员 HTTP、CLI 和 MCP 可管理同一工作区的 Todo 和备忘，查看发布回执与冲突。CLI 可用 `todo lists`、`todo tasks`、`memo list`、`memo get` 和 `productivity conflicts`，MCP 有对应的下划线工具名。用 `schema` 查看参数。CLI/MCP 默认只读，写入需要管理员授权，删除整张清单还需要在网页上单独审批。保留操作 ID，回执不明时先查询 `operations.receipt` 和当前记录。

## 从 0.8.2 原位升级

1. 确认应用中心已安装官方 **Node.js 22**。如需升级前备份，可在「备份与维护」创建一份新的加密备份，并保留原备份。
2. 下载 `dormpanel-schedule-manager-0.8.3.fpk`，按 `SHA256SUMS.txt` 校验。
3. 在 fnOS「应用中心 → 手动安装」选择该文件，确认对已安装的 DormPanel Schedule Manager **原位升级**。`install-local` 会先卸载已有应用，可能清除应用数据，请使用应用中心的升级入口。
4. 打开应用，核对工作区、课程、Todo、备忘和同步状态。正常升级会保留连接、证书、备份、安装及 Writer 身份，以及本地待发布状态。新版创建的备份标记为 0.8.3，可验证和恢复合法的 0.8.3 及此前支持的备份。

## 创建或加入共享工作区

在「课程表与共享」选择独立的 Sync v3 工作区。创建时使用独立空目录，并明确选择支持 Todo 和备忘的 DPV3/4。加入时核对现有 DPV3/4 数据集，再让 X08E、Phone 和 fnOS 各自明确加入同一个数据集。打开主导航的「Todo」或「备忘」开始管理。

升级不会切换或迁移任何已有数据集。v2 和 DPV3/3 工作区可继续用于原有业务，启用效率同步请另建兼容工作区并明确加入。保留旧目录和历史。只让支持相应记录类型的客户端写入 DPV3/4。

## 保存、发布和恢复

- **已保存 / Pending**：编辑先保存在本机。点击「检查并同步」后，核对是否取得远端回读确认。待发布状态会保留，其他设备需各自同步才能接收。
- **UNCERTAIN**：远端写入结果暂不能确认。恢复连接后用「检查并同步」核对已有尝试，保留待发布状态和历史。
- **冲突**：比对共同基线、本机与远端记录。课程、Todo 和备忘同时冲突时，打开「查看完整共享冲突」逐页检查。决定会应用到整次冲突，确认后再检查并同步。
- **恢复保护**：在「备份与维护」先验证备份并核对预览。恢复后需验证已知历史才能重新发布。应用加密备份和 WebDAV 历史归档覆盖的内容不同。
