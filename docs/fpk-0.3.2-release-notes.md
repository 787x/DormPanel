## 本版能力

管理员通过 fnOS 桌面管理独立工作区，连接 NAS 授权本地目录或 HTTPS WebDAV。各工作区独立保存课程、导入预览、同步候选、回执和冲突；切换及正常重启保留状态。课程、事件、日期调整、学期配置及 ICS / 湖北大学 CSV 导入沿用已有编辑能力。

使用 Sync v2 不可变追加提交；本地保存与网络分离，按需同步，无后台轮询。支持三方合并、关联冲突展示与确认决策。已绑定连接更换端点前验证 datasetId、已知提交与完整历史；重复数据集不能绑定为第二个工作区。所有提示和确认使用页面内对话框。

原安装 writerId 保持不变。真实手机、X08E 的未修改正式 Android 0.1.2 已通过正常公网 HTTPS WebDAV 完成接收、发布、独立修改合并及 FPK 冲突决策接收。X08E 正式版当前从界面首次创建 v2 数据集，再由其他编辑端绑定；其界面没有首次绑定已有 v2 数据集的入口。

## 安装与备份

使用应用中心的正常手动安装/原位升级。不要用卸载重装或 `install-local` 代替升级。PR39 已记录标准包升级到本候选的过程，PR40 重新核对了原包和实际安装载荷。

升级及数据处理前完整备份实际 `var`、`etc` 内容，并解包读取校验，不能仅保存软链接。必须包含 `catalog.json`、所有 `workspaces/<UUID>/workspace.json`、`identity.json`、连接凭据与证书配置，以及私有本地提交。授权外部目录及 WebDAV 历史应另行保留。原 PR38 `workspace.json` 是迁移前副本，不代表 0.3 的最新全部工作区；回退旧版不会自动带回新编辑。

## 权限与限制

- 网关入口仅管理员可访问；普通账号及未登录伪造管理员 Header 均不能读取管理数据或修改课表。服务以独立包用户运行，私有目录 0700、Socket 0600；root 与包用户仍属完整信任边界。
- 本地目录应通过 fnOS 官方授权，并在授权变更后重启应用更新目录列表。实际文件系统权限仍必须满足；只读或撤销授权时保留本地修改并拒绝危险写入。可通过同一物理目录的 WebDAV 入口读取本地提交。
- 公网 fnOS 测试域名在验收中出现间歇 DNS 失败；失败显示离线并保留本地数据，解析恢复后正常重试。不保证特定域名或外部网络可用性。
- 未验证 ARM、其他品牌 WebDAV、最大图多工作区内存峰值、真实断电/磁盘满及长时间压力。正常重启与短窗口资源采样通过，不能据此承诺无限容量或长期零增长。
