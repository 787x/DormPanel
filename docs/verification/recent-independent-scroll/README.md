# 近日课程双列独立滚动

基于已合并 PR72 的 main `63684b0`。按用户后续要求，将原先共同滚动改为今天、明天各自独立滚动；本记录取代 PR72 文档中的“近日使用同一滚动集合”设计约定。

- 两个并排的原生 ListView，共用固定头部和同一次正式课表读取。每列适配器身份包含 widget ID、进程及列编号；刷新通知覆盖两列。
- 每列只取自身课程和空状态，不保留另一列的补齐空行。稳定行身份只依赖该列业务课程；今天变化不会改变明天条目身份。
- 今天仍为尚未结束课程，明天仍为全部课程。颜色、失败处理、预算、时间与点击规则不变；周组件和旧两种今日组件保持原行为。
