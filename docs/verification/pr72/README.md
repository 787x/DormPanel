# PR72：Phone 原生滚动课程小部件验收

基线：PR71 合并提交 `2b8dac25bf9ac6a15ccf7241f31489bae5434392`。本轮只安装 `.pr72testbed`；没有安装到 X08E、升级日用 APK、改版本、改同步协议或发布 Release。

## 实现

- 保留紧凑／宽版今日课程，新增近日课程、一周课程两个独立入口。两个新部件使用原生 ListView / RemoteViewsService，固定头部、独立纵向滚动和纵向尺寸调整。
- 近日课程：今天未结束课程与明天全部课程配对成同一集合，无固定两门／三门上限；独立空状态，名称、地点、真实时间和共享颜色，跨日时间有标记。
- 一周课程：默认按节次、7 天，每实例可改实际时间、5 天。复用 PhoneWeekView 的 WeekLayout / WeekAxis；节次表无效、不统一或时区不符时回退实际时间并标注。连续课程保持完整色卡，真实重叠分列，跨日按天裁切。深浅主题与 CourseColors.background / ink 一致，夜间纯黑；非今天日期标题降低强调。
- 周网格按需生成 96dp 高的小块，单块不超过 800×192 像素，不保留整周 Bitmap、截图或固定课程模板。各块共享同一全局坐标轴，文字和圆角跨块连续；原生集合负责触控滚动。每列叠加原生点击／无障碍入口，点击打开日期，不使用可能过期的课程索引。
- 四种部件共用原有 WidgetRefreshCoordinator 和正式 Store 读取；未修改最多两个未回调物理读取的约束。集合服务不读取 Room，不同步等待异步回调。渲染缓存只保留当前快照及四个有限视图变体；周投影预算 512 门，超限显示提示而非静默截断。
- 普通刷新保留适配器身份和稳定行 ID。进程重建、模式／天数变化使用新适配器身份，防止 Launcher 沿用不对应的旧行缓存；高度变化保留集合。读取失败／超时隐藏旧集合并显示错误。午夜、课程边界及恢复调度沿用非精确 alarm。

## 实际验证

| 验证 | 结果 |
| --- | --- |
| Phone JVM / 构建 / Lint | `testDebugUnitTest assembleX08eTest lintDebug` 成功；41 项 JVM，0 failures。包含剩余今日／全部明日、短课、七天、跨午夜／跨周、默认节次与显式时间、5 天范围；原有协调器竞态测试继续通过。见 build.txt 和 TEST-*.xml。 |
| API 28 标准 Launcher | 真实添加四种隔离部件（原有紧凑／宽版与两个新部件），两个新集合实际滚动、固定头部。实际拖动高度，近日集合可视范围从 y=97–244 改为 y=97–607；周集合从小高度增加至 y=133–607。不是仅调用 updateAppWidgetOptions 的模拟验证。 |
| MIUI API 33 | 在新桌面页实际添加两个新部件，显示正式 Store 的隔离本地课程与有效学期导入课程，实际上下滚动。7 天节次轴与 5 天实际时间轴均已显示。保留已有 PR68 组件，未移动它们。 |
| 每实例设置与重建 | API 28 / MIUI API 33 各 1 项 instrumentation 通过：修改时间模式／天数，重建 Activity 后保留选择，保存后验证配置和五天实际时间投影；缺省配置仍为节次／七天。MIUI 首轮等待系统对隔离测试 APK 的启动允许，共约 202 秒，不是生产配置需要新权限。 |
| 读取失败与恢复 | API 28 / MIUI API 33 各 1 项通过：正式读取成功后注入 Fake 失败，近日及全部周模式旧缓存清除、错误明确；恢复正式 Store 后重建成功。API 28 此时四种隔离实例并存。不是破坏真实 Room 的故障实验。 |
| 滚动与点击 | API 28 / MIUI API 33 各 1 项通过：在真实 Launcher 的近日列表注入手指滚动，仍停留 Launcher；随后点击明日列，进入 Phone 并验证 selected 为明天。 |
| 有效学期导入 | 两端通过正式 commitImport 保存隔离 CSV 来源与课程后读取刷新；MIUI／API 28 均验证有效节次轴。API 28 初轮因模拟器 UTC 与课表时区不同而按设计回退；仅调整隔离模拟器时区后通过。 |

首次点击测试遇到 UiAutomation 尚未建立根节点、Launcher 正处于调整尺寸模式；等待根节点并退出该模式后，两端最终运行通过。未把失败的早期运行当作 PASS。

## 尚未通过的验收与限制

- **MIUI 的手动高度调整仍未验证成功。** 当前 Launcher 长按只出现编辑／移除和外框，多次尝试上下边缘拖动后，周列表范围仍为 y=1014–1713。已声明 vertical、minResizeHeight 和 maxResizeHeight，API 28 实际尺寸调整成功；不能据此声称 MIUI 尺寸调整也通过，也未认定所有 MIUI 都不支持。这是本 Draft 保留的兼容验收阻塞，尚不满足全部 Done Criteria，不转 Ready。
- MIUI 四种本轮隔离实例同时添加、两个旧组件的本轮完整配置回归、删除／重新添加、设备重启、自然午夜／跨周、系统主题与时区切换后的长期观察尚未完成。没有将已有 PR66 历史证据冒充本轮实测。
- 新增集合的连续迟到回调／超时仍主要由既有确定性协调器测试覆盖；没有新增真实 Room 永久阻塞试验。真实远端同步接收、共享颜色提交、所有 XLS/ICS 导入替换到 Launcher 的逐项联动矩阵未执行，继续复用已接通的正式业务提交信号及共享核心。
- 极短课、重叠密集列及课间的自定义时间课程会受可用像素限制，保留真实几何与无障碍时间信息，可点击日期进入 Phone；不为可读性伪造课程时长。周小部件没有课程详情写入入口。
