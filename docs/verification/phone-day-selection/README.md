# 日视图选中日期高亮

日视图日期按钮的蓝色背景改为跟随当前选中日期。今天的大圆点、选中非今天的小圆点及其原有标记规则保留；周视图仍按原来的今天列高亮规则。

Phone 隔离构建与 Lint 成功。API 28、MIUI API 33 各 1 项 Android 定向测试通过：在 Activity 中设置选中本周另一天并渲染，检查选中按钮背景为蓝色、今天按钮不再为蓝色，同时检查大圆点、小圆点和 isSelected 状态。MIUI 测试约 62 秒包含 Activity 启动等待。api28.png 为实际应用画面，今天周四带大圆点、选中周五带小圆点及蓝底。

仅安装 .pr72testbed；不修改日用包、课程或同步数据。此修改不涉及课程投影或同步控制器，未重复相关业务测试。
