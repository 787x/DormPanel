## 实际修改

- 时间/节次网格的课程卡片改为单个可点击 View 绘制文本，读取原生 TextView 的字体、行距、断行及连字符参数，沿用原显隐规则、字号、padding、Ripple/配色和完整无障碍描述。宽度和显隐组合不变时复用文字 Layout，完整容纳的单行复用 BoringLayout；需要省略或换行时保留 StaticLayout。经典列表的自然高度路径未见稳定收益，继续保留原生多字段卡片，没有为了统一而强行替换。
- 首个 BoringLayout 省略实验有像素差异，已拒绝；当前版本逐尺寸像素对照通过。字体缓存使用弱 Context 键，值只有配置快照及 TextPaint 参数，不缓存 View 或 Activity。配置变化重新提取，颜色由各卡片独立更新。
- X08E 在原手势容器内转正，不再摘下预览、重建顶部导航并重新挂载；仅移除旧内容、启用目标页和更新周次文字。Phone 保留原 `takePreview()` 路径。
- 时间线只在可见且坐标变化时设置布局参数，避免给七条隐藏线重复触发整页测量。可见位置、颜色、今天背景和主题逻辑不变。
- 既有 Epoch、三周数据边界、有限补建、触摸阈值及默认关闭规则保留。未改 Home/Apps、Phone 视觉、课程业务或同步，没有 Bitmap 页面缓存、新依赖或高频常驻任务。

## 同条件 A/B 与原始样本

同一物理 X08E / API 28 / 1280×800，每周 21 门相同隔离课程。基线使用从 `bd5765d` 保留的原生卡片及摘下/重建转正路径；instrumentation 的 `renderer=legacy` 注入仅用于对照，正常应用为空。相同采样工具、手势比例、外观、数据与场景；每布局每场景 6 个样本，原生手势每布局 3 次。新页/重复上下文的定义沿用上一轮，不称为 OS 重启冷启动。

按顺序先基线再候选，没有锁定 CPU 频率/温度，结果用于简单比较，不声称统计显著性或硬件面板延迟。OnDraw 不等同扫描呈现。原始阶段和完整 FrameMetrics 均保留，不剔除最慢样本。`cold` 在首个 MOVE 前清空数据缓存；`release` 在首次 25% MOVE 后立即松手，不再先走到 80%。零动画实机测试保存原值，finally 恢复，最终读取为原来的 `null`。
