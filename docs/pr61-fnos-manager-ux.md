# PR61 fnOS 课程表管理体验验收

基线：PR60 合并提交 `dd541922379b6235b748b2e6a4483478e5a4889f`。本次仅调整 fnOS 网页与最小只读投影，不变更版本号、Android、同步协议、持久化格式、合并、Writer 事务或备份加密格式。

## 实现范围

- 四个固定导航入口：课程表、课程表与共享、历史版本、备份与维护；二级页面可直接返回课表。当前课程表及复用 PR60 映射的状态始终有独立摘要。
- 保存连接后立即提供下一步：保留当前课程关联连接并继续 v3 迁移，或者建立不复制本地课程的独立空白课程表。新建表单默认 v3，v2 需明确选择；建立本机配置与远端创建/加入分别确认。加入只选择已验证目标，没有发现目标不会创建第二份共享数据。
- 当前课程表按未发布、待确认、冲突、断线或恢复状态突出相应动作。端点变更、v2→v3、迁移恢复、移除配置及 RAW 诊断保留在高级操作；未完成事务提供明显恢复入口。
- v3 普通列表只呈现已验证的类型 2/3 业务版本。证据视图保留 Descriptor、Transition、Epoch、路径、哈希和全部引用，筛选使用单个表单。`verifiedAt` 明确为本机验证时间，不推断作者创建时间或完整时间线。
- `/api/history?view=business` 每次最多扫描请求 limit 个本机元数据项；不读取完整快照或远端，不跳过稀疏页游标。列表最多展示一页，可前后翻页；快照按八类集合展开并每页读取 40 条。v2 复用原有不超过 256 提交的历史接口，网页按 40 个版本分页。
- 每个版本可查看内容、与当前比较、预览恢复；v3 多父关系逐父比较，不选择任意单父代表全部变更。列表不预先解码全部业务快照，变化摘要在用户请求比较时计算。v2 增加只读 `current` 比较基准，保留原有版本间比较。
- 回退预览明确“当前→目标”，最终确认沿用原 token、版本、前沿与身份检查。回退创建新提交并保留旧历史；结果复用刷新后的同步事实，不以旧回执存在推断新提交已发布。
- 高级历史工具区分共享历史归档、空间统计、本机冗余快照整理和 v2 精简换库。归档位置、清单进度与覆盖边界可查看，中断任务按原目录继续。容量同时显示可读值与精确字节；内部可复用空间与实测文件释放量分开。完整诊断证据可展开，不提供远端批量删除。
- 备份页区分应用状态加密备份与共享历史归档；展示口令验证、将替换的应用范围和外部依赖。切换文件前先撤销旧 token；验证失败、换目录、换课表、离页或版本变化均撤销恢复能力。
- 课表、编辑数据与管理接口分别处理失败；分页、页面、工作区和输出请求设有作用域检查。操作锁防重复提交，离页会释放旧页面的临时禁用状态；结束后重新计算回退、恢复及维护资格。确认按钮实际使用调用方传入的标签。

## 验证方法与环境

浏览器使用 Windows Node 24.19.0、Playwright 1.56.1 和 Edge；全部服务、安装身份、凭据、远端对象及工作区为临时合成夹具。覆盖 1280×800 和 390×800；目录选择另复用原窄窗口用例。截图经目视检查，页面无横向溢出；长版本列表在有界区域内滚动，回退确认固定在预览操作区。

服务层使用 WSL Ubuntu、Node 22.16.0，在 Linux 临时目录运行原有历史、归档、整理和备份测试，未降低 Linux 安全文件发布要求。Windows 的同组测试最初为 25 通过、48 按平台跳过，随后已在 Linux 全部实跑。

## 验证边界

- 网页目录列表和部分归档/备份高风险交互使用受控响应；真正的文件权限、归档回读、备份解密与恢复由上述 Linux 服务层测试覆盖。浏览器未对真实 NAS 课表做恢复、换库或清理。
- 未连接日用 WebDAV，未升级或部署 NAS FPK，未安装 Android，未打 tag 或发布 Release。
- 构建生成的是 FPK 工程；本机未安装官方 fnpack，未执行最终 FPK 打包及 `verify:package`。没有将工程构建通过报告为正式安装或升级验收。
- 普通 WebDAV 的完整目录视图、未知设备停写和旧历史物理回收资格仍没有被证明；此 PR 不改变这些协议边界。
