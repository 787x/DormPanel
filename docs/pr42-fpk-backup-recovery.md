# PR42：FPK 备份、恢复与工作区按需加载

日期：2026-10-22（Asia/Shanghai）。基线为合并 PR41 后的 main `cfe30fa`。本 PR 不修改 Android、Room、DPC2 / DPSS/1、Home Assistant、WebDAV 服务或 FN Connect，不创建 tag 或 Release。

## 使用和覆盖范围

管理员从课表页面进入“备份与恢复”，选择 fnOS 官方应用共享目录或已授权目录中的现有子目录，输入至少 12 字符且 UTF-8 不超过 1024 字节的口令，创建加密备份。私有 var 不可作为导出位置。应用不保存口令；忘记口令无法解密。

备份包含 identity（原 writerId 和新增 installationId）、完整 catalog、全部注册及保留的工作区文档、兼容迁移文件、旧 archive JSON、恢复发布隔离信息、旧 etc/webdav.json（存在时），以及私有 local-data 中的有效提交。完整 workspace 文档原样保存课程、baseline、frontier、graph、checkpoint、pending/raw/capture/attempted、abandoned、receipt、未解决冲突、异常和扩展恢复字段。PID、Socket、日志、临时文件、派生摘要、预览暂存及旧恢复前快照不属于本次恢复的必要文件。

WebDAV 和用户授权 NAS 目录的提交历史**不被默认复制**。清单逐工作区记录连接 ID、datasetId、端点身份、已知 SHA-256、frontier、异常路径及是否包含私有历史。未绑定工作区单独说明；预览显示名称、课程数、候选和冲突，并将详细身份/历史信息折叠。验证外部依赖只读，不发布、不创建远端目录、不执行合并。外部不可达不会阻止查看已认证的本地备份，但不表示远端已完整备份。

文件列表中的未解密产物仅显示文件大小、文件时间及“待口令验证”，不会因扩展名正确便显示为有效备份。成功验证后展示真实创建时间、FPK/格式版本、覆盖范围和外部验证结果。恢复需要未过期、绑定同一管理员的预览令牌和输入“恢复应用数据”确认；预览后 catalog 或任何注册工作区变化均须重新验证。恢复成功清空旧导入预览及 CSRF 会话，其他旧页面必须重新读取，不能利用回退的 revision 重放旧请求。

## 归档格式和安全边界

`DPBK0001` 为无压缩、顺序文件容器，不使用通用 tar/zip 解包。固定头 52 字节：magic 8、随机 salt 16、随机 GCM nonce 12、认证 tag 16；前 36 字节为 AAD。密文为 `U32BE 清单长度 + UTF-8 JSON 清单 + 按清单顺序拼接的原始文件字节`，不能存在尾随字节。清单含格式版本、应用版本、创建时间、身份、依赖，以及每个文件的名称、长度和 SHA-256。

Node 22 内建异步 scrypt：N=32768、r=8、p=1、32 字节密钥、64 MiB maxmem；AES-256-GCM，96 位随机 nonce、128 位 tag。算法和参数由格式版本固定，不接受输入指定任意 KDF 成本。派生密钥使用后清零，口令不落盘。流式加解密使用有界块，认证完成前不解释明文或修改有效数据。

资源限制：清单 1 MiB、4096 文件、单文件 64 MiB、总文件字节 256 MiB；每次开始私有暂存前检查至少 768 MiB 可用空间。预算不足时整体失败，不输出不完整备份。最多八个、有效期十五分钟的恢复预览，无后台轮询。它们在后续验证时清理过期项；重启清理已失效暂存，只保留最近一次成功恢复前快照。暂存和快照在应用私有 0700 目录，文件 0600，不进入普通状态 API。

目标目录复用 LocalGrants：按授权根 ID 和相对目录访问、Linux 逐级 O_NOFOLLOW、目录 fd、dev/inode 校验；无任意路径下载或读取接口。输出使用 0600 隐藏暂存文件，完整写入并 fsync，**重新读取实际密文、认证解密、校验所有长度/SHA-256/领域状态后**，硬链接排他公开文件名并 fsync 目标目录。失败不公开半成品。归档仅允许明确的应用文件路径和普通文件；路径穿越、异常目录、链接、重复文件名、截断、额外字节及预算超限均拒绝。

API 继续使用私有 Socket、管理员身份、CSRF/同源校验、JSON 请求限制和 catalog revision；没有敏感备份下载路由。普通 NAS 用户、未认证请求以及 TCP 伪造 Header 不能通过管理 API 读取备份。拥有 root 或应用包用户完整权限的主体仍属于既有信任边界。

## 恢复事务和发布隔离

第一版只支持 writerId **及 installationId 全部相同**的安装。0.3.2 首次升级仅给旧 identity 增加一次随机 installationId，writerId 不变；没有身份接管、跨 NAS 迁移或重新生成 writer 后继续旧 pending 的入口。

恢复先完整认证归档并验证注册工作区、连接、凭据/证书配置、原始图缓存、可校验历史、私有提交和候选身份。发布回执已保存而 graph 尚未来得及 observe 的合法状态也允许归档：缺失的缓存前沿必须有持久化 checkpoint 哈希，不能伪造闭包或将外部依赖标记为离线完整。

维护栅栏拒绝同步、配置和其他备份恢复并发，等待已排队本地事务结束；Workspace 自身也拒绝维护期间写入。恢复前再次验证暂存和预览版本，完整保存旧状态，再原子持久化 `.restore-journal.json` 决策。决策前失败保持旧状态；决策后服务停止提供数据/写入 API，故障或重启只继续完成已验证的新状态，不重新服务部分新旧文档。启动在创建 Catalog 和监听 Socket 之前处理日志。所有文件完整切换并回读校验后才删除日志和新暂存，保留恢复前快照。

私有提交也保持不可变：已有同 UUID 不同字节在决策前拒绝，备份后新增的私有提交继续保留；不会用恢复覆盖或清理外部 WebDAV/NAS 历史。恢复后的 workspace 帧与归档逐字节一致，另存独立 `restore-guards.json`。第一次相关网络操作先完整只读验证端点、dataset 和已知历史，再由原 SyncEngine 处理 pending/回执/冲突；未验证前不能 PUT。恢复本身不等于同步，不执行三方合并。

恢复依赖文件系统的 fsync、同目录原子 rename 和硬链接语义。真实掉电、介质损坏或外部管理员篡改暂存并不等同于本轮注入异常测试；损坏的已提交恢复暂存会安全停止启动，保留旧快照供管理员处理。

## 按需加载与升级

启动仅加载活动工作区；端点迁移恢复日志涉及的其他工作区是明确例外。管理列表读取可丢弃的 `summary.json`，以 workspace 文件的 dev/inode/size/mtimeNs/ctimeNs 核对。缺失、损坏、过期或无法读取时显示“待检查”，不显示“已同步”或“无待发布修改”。切换时验证实际帧，损坏或缺失的已注册帧不会走空工作区新建分支。

并发 load 共享同一个 Promise/Workspace 和事务队列。网络互斥、首次绑定串行身份检查、catalog/帧 revision、端点更新意图日志保持。缺失摘要影响重复绑定检查时按需读取实际帧修复，不能依赖未知摘要判断 dataset 不重复。全部请求结束后释放非活动、非同步、无排队事务的缓存；旧引用拒绝写入。备份从静止快照逐个验证工作区，不为备份把所有非活动帧长期载入 Catalog。

生产启动脚本用继承 fd 的 flock 排他保护同一 var，即使并发 start 也不能启动第二个 Writer。原有 package 用户、0700 target、0600 Socket 和管理员网关保持。

## 真实 fnOS 验证和候选

真实测试 NAS 上先正常停止 0.3.2，完整归档 var/etc，实际读取全部 22 个持久化文件并逐项对比文件集合、长度、SHA-256。首次原位升级保留原 writerId，其余 21 份文件逐字节一致，仅 identity 新增 installationId。随后把原五工作区的 var 和 etc **原目录封存**，所有恢复实验使用独立合成状态；没有对原工作区执行应用内恢复，没有访问日用 NAS“课表ics”或 Android。

为覆盖最终确切哈希，中途未发布开发候选被淘汰。fnOS 拒绝相同版本覆盖安装，因此曾在原目录封存后卸载临时实例、重建 0.3.2 基线并放回合成测试状态，再经应用中心“从 NAS 添加”走真正的 **0.3.2→最终 0.4.0 原位升级**。基线重建/卸载重装本身不计作升级证据。最终升级后，四工作区的 10 份身份/catalog/完整帧/私有提交与升级前逐字节一致，最终 FPK 的 **267 个普通载荷文件**与已安装 target 全部 SHA-256 相符。

基线准备出现过 CLI 返回 10500（退出码仍为 0）及旧 0.3.2 进程残留：移动运行时 PID 文件后，准备脚本第一次按别名而非规范路径检查进程，未能停止旧进程。发现后按包 UID 和精确 Node/server 路径停止残留，重新核对全部合成帧未改变，再重新启动并升级；没有把 CLI 退出码当成成功，也不将该准备过程算作最终单 Writer 验收。最终已安装 0.4.0 只有一个 Writer，fd 9 实际持有 var 的 flock，第二个真实 flock 获取返回 1，确认内核拒绝。

## 限制

加密备份只在已验证的 Linux/fnOS 文件系统路径开放；Windows 运行相关安全本地文件系统测试明确跳过。跨安装、跨 NAS 迁移和 writer 接管不支持。没有 Android 三端重复验收、四小时 soak、冷盘/最大协议容量压力、ARM 或其他 fnOS 版本、真实掉电或介质满实测。外部依赖是否能恢复取决于原服务器、授权和完整历史；不可将应用归档宣传成整个远端数据集备份。
