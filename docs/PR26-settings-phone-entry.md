# X08E 统一扫码配置

从 DormPanel 首页下滑，点控制中心右上方的「扫码配置」。Home Assistant、WebDAV 和天气设置中的同名按钮打开同一个门户。用同一可信局域网里的手机扫 X08E 上的二维码。也可以在手机浏览器中输入二维码旁显示的完整地址。一个会话中可以填多个分区，切换分区会保留本页输入。

**只在可信局域网使用。门户使用 HTTP，填入的凭据会在局域网明文传输。** 不要把临时地址发给其他人，也无需配置端口映射。会话最多开放 10 分钟。发送最终配置、在网页取消、在 X08E 关闭扫码窗口或将应用退到后台都会结束会话。「申请生成 Ed25519 密钥」和「先保存和风凭据并继续」各自需要在 X08E 确认，完成后可在同一会话继续。关闭会话会丢弃待确认请求，已确认的凭据和密钥会保留。

## 填写和保存

- **Home Assistant**：填写服务地址和长期访问令牌。地址可用 `http://homeassistant.local:8123`，也兼容 HA 的 WebSocket 地址形式。新设备首次填写后默认启用 Home Assistant。高级选项可选择连接模式和首选天气实体。只有规范化后仍为同一服务端点时，留空才能复用令牌。更换协议、主机、端口或服务路径时，保存和测试都要求重新输入对应服务器的令牌，包括演示模式下的改址。设备端「Advanced settings」默认折叠，可调整屏幕中继名称和其他 HA 辅助实体。首选天气实体及测试连接仍可在设备端直接操作。
- **WebDAV**：填写 HTTP(S) 服务地址、用户名和密码。已有配置只有在服务器协议、主机、端口、用户名和 TLS 信任一致时才可以留空复用密码。更换服务器且已有文件导入绑定时，X08E 会要求确认移除旧绑定。已导入课程保留，之后可重新选择导入来源。
- **和风天气**：填写专属 API Host，选择 JWT 或 API Key。API Key 留空只会复用同一专属 Host 上已保存的 Key。刷新模式和本机 UTC 月预算可以单独提交。自定义各数据项周期继续在设备端调整。
- **天气地点**：可编辑已保存地点的名称、IANA 时区和坐标。新地点可以使用自己取得的坐标，也可用已经保存的和风凭据搜索城市或区县。首次填写时，先用「先保存和风凭据并继续」在 X08E 完成确认，再返回同一页面搜索。搜索后选中候选，自行填写收藏名和时区，再加入待确认列表。X08E 确认时会核对该编号确实在和风公开目录中。公开目录未收录的地点请手填自有坐标。地图选点和 HA 来源管理在 X08E 天气中心完成。

勾选要发送的分区，点「发送待确认配置」。天气地点只有加入待确认列表后才会发送。未加入列表的草稿可继续编辑或放弃，其他分区和已排队地点会保留。在 X08E 核对「待保存配置」，选择「确认应用」后才能写入设置。X08E 会分别报告各项目的结果。留空或更换凭据的影响会在摘要中说明。旧密码、令牌和私钥不会回填到网页。

## 和风 JWT 首次配置或换钥

1. 在手机门户的「和风天气」点「申请生成 Ed25519 密钥」，在 X08E 点「确认生成」。也可从设备「天气服务与地点 → 和风服务配置」生成或重新生成。待注册私钥保存在设备的加密存储里。已有 JWT 继续使用当前密钥，直到确认保存新的凭据。
2. 在扫码门户的「和风天气」选择待注册的新密钥，展开「查看、复制或下载公钥」。复制含首尾标记的完整 PEM，也可直接在 X08E 选择或复制。公钥旁有两个十六进制 SHA-256 值。「和风公钥文本」按官方文档对导出的完整 PEM 去除首尾空白后计算，保留内部 LF 换行。上传时请复制本页的原始 PEM。「SPKI DER」基于解码后的二进制公钥。扫码过期后可以重新打开会话，继续使用同一待注册密钥。
3. 在和风控制台进入「项目」，选择目标项目并添加 JSON Web Token 凭据，把公钥 PEM 粘贴到上传公钥文本框并保存。[和风官方凭据创建说明](https://dev.qweather.com/docs/configuration/project-and-key/) · [和风官方认证说明](https://dev.qweather.com/docs/configuration/authentication/)
4. 在门户填写控制台为账号分配的专属 API Host。把项目中刚创建的**凭据 ID**填为 `kid`，控制台设置中的**开发者 ID**填为 `iss`，创建凭据所在的**项目 ID**填为 `sub`。选择与上传公钥对应的签名密钥。[和风 API Host 说明](https://dev.qweather.com/docs/configuration/api-host/)
5. 点「先保存和风凭据并继续」，在 X08E 选择「保存并测试」或「仅保存」。门户可查看进度，完成后可直接继续搜索天气地点。也可随其他分区一起最终提交，再到设备「和风服务配置」点「测试已保存凭据」。测试使用正常天气请求并消耗本机请求额度。认证失败时，核对专属 Host、三个标识、签名公钥及设备时间。

已有 PKCS#8 私钥可在 X08E 的和风设置导入。应用可从有效的 Ed25519 私钥导出对应公钥。保存或更换已生效凭据、重新生成待注册密钥、清除凭据均会按设备界面提示确认。清除和风凭据也会删除待注册密钥。

## 备用操作

- 扫码失败时，手动在手机浏览器输入设备显示的完整临时地址。网页打不开时，检查两台设备是否在同一个可互访的可信局域网，避开访客网络的客户端隔离。
- 没有可用局域网时，可通过 X08E 各服务的独立设置手动填写。天气地点可在天气中心手动填坐标或从离线地图选点。
- X08E 软键盘暂时不可用时，可在局域网用手机填写，或在独立设置中用外接键盘输入。表单支持滚动，设备仍保留原有测试和保存入口。
