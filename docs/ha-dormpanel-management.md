# DormPanel 的 Home Assistant 页面与概览卡片

## 安装与连接

解压 `DormPanel-HA-0.1.3.zip`，将其中的 `custom_components/dormpanel/` 复制到 HA 的 `config/custom_components/dormpanel/`，重启 Home Assistant。从「设置 → 设备与服务 → 添加集成」添加 DormPanel。升级已有集成时，直接覆盖集成目录中的代码再重启，保留原有配置条目及 HA 的存储数据。

在 X08E 控制中心的 Home Assistant 设置中填写 HA 地址和长期访问令牌。首次注册需要管理员连接。连接成功后，从 HA 侧边栏进入「DormPanel」，在设备概览选择已注册设备，查看版本、上次注册时间及支持的文件类型。

## 从侧边栏控制设备

使用 HA 管理员账户打开「DormPanel」，从顶部选择设备。在线表示设备已建立原生控制会话并且已上报状态。「设备信息与诊断」显示版本、上次注册时间、安装 ID 和可接收文件类型。「设备管理」可移除不再使用的设备。

| 区域 | 可操作的设置 |
| --- | --- |
| 显示与外观 | DormPanel 窗口亮度（1–100%）、卡片背景不透明度（0–100%）、浅色/深色、跟随系统亮度 |
| 系统亮度与音量 | 系统屏幕亮度（1–100%）、系统自动亮度、媒体音量 |
| 屏幕与启动 | 黑屏、屏幕常亮、开机启动 |

释放滑块或松开调整键时发送一次设置。等待设备确认期间，同一设备暂时不能接收本页面或其他 DormPanel 卡片的新设置。设备可能将音量换算成最接近的实际档位；界面显示设备报告的实际状态。X08E 本机的修改也会自动出现在 HA 页面和卡片中。

未建立原生会话、设备离线或 HA 断线时无法执行设置。超时或执行失败时，先核对界面重新读取的实际状态；断线后要等重连并重新读取状态。失败或重连不会自动重发命令。

- 调整系统亮度或开关系统自动亮度前，先在 X08E 上授权 DormPanel 修改 Android 系统设置。系统自动亮度开启时，需先关闭它才能手动调整系统亮度。
- 跟随系统亮度开启时，不能单独调整 DormPanel 窗口亮度。
- X08E 不支持用媒体音量控制发送 0% 静音；实际百分比由设备档位决定。开启黑屏后可在本机触摸屏幕退出。

## 原生实体与旧 Helper

使用支持原生控制的 HA 集成和 X08E 应用。设备重新连接 HA 后，在「设置 → 设备与服务 → DormPanel」可看到设备及其控制实体。每台 X08E 的实体独立，可以加入 HA 标准仪表盘或用于自动化。设备改名和正常重连保留实体身份。

| 实体类型 | 设置 |
| --- | --- |
| 数值 | DormPanel 亮度、系统亮度、媒体音量、卡片背景不透明度 |
| 开关 | 黑屏、系统自动亮度、跟随系统亮度、屏幕常亮、开机启动 |
| 选择 | 明暗主题 |
| 诊断 | 设备连接、应用版本、已上报的控制能力 |

已有 Helper 配置继续保存在 X08E 的 Home Assistant 高级设置中。连接旧版 HA 集成时仍可使用。探测、注册或会话建立遇到临时故障时，设备会自动重试，有效的 Helper 绑定可在恢复期间处理实时变化。原生会话建立后会停用 Helper 联动，并同步设备当前实际状态。升级已有 HA 集成和 App 时，保留各自原有配置和应用数据，并重新连接。

使用侧边栏、概览卡片和原生实体不需要创建 Helper。页面和卡片的控制要求设备支持原生会话。

## 添加概览卡片

卡片资源由 DormPanel 集成提供。资源注册只需完成一次，可供多个仪表盘使用。

- **由界面管理资源**时，使用管理员账户打开「设置 → 仪表盘 → 右上角菜单 → 资源」。如果菜单没有「资源」，在个人资料中启用高级模式。添加 `/dormpanel_static/panel.js?v=0.1.3`，类型选「JavaScript 模块」。
- **已使用 YAML 管理资源**时，将下列条目加入现有 `lovelace.resources` 列表。重新加载仪表盘资源或重启 HA，再刷新浏览器。[HA 资源注册文档](https://contributors.home-assistant.io/frontend/custom-ui/resources/)

```yaml
- url: /dormpanel_static/panel.js?v=0.1.3
  type: module
```

刷新 HA 页面后，编辑目标仪表盘，在卡片选择器中找到「DormPanel 概览」，或通过手动卡片填写以下配置。可选的 `device` 使用管理页面所显示的完整安装 ID，指定该卡片优先显示的设备。卡片仍可切换设备。

```yaml
type: custom:dormpanel-overview
# device: 设备安装 ID
```

卡片提供与侧边栏相同的 10 项设置。点击「设备信息与诊断」「发送文件与传输记录」或「设备管理」展开其他操作。每张卡片的设备选择和展开状态各自独立。

侧边栏脚本地址会随文件内容变更。升级时，把已有 Lovelace 资源条目的 `v` 值改为 `0.1.3`，刷新所有打开的 HA 页面；如果仍看到旧卡片，重新加载仪表盘资源并强制刷新浏览器。保留原有卡片配置即可。

## 文件发送与记录

1. 在侧边栏页面或卡片中展开「发送文件与传输记录」。设备管理、上传及记录需要管理员权限。
2. 选择 ICS、CSV、湖北大学 XLS 或 APK，选择文件并勾选兼容设备。课表最大 1 MiB，APK 最大 256 MiB。可选保留时间为 1 小时、24 小时或 7 天。
3. 上传成功后，HA 暂存文件并通知目标设备。课表需在 X08E 上预览并确认导入。APK 由设备校验，安装需经过本机与 Android 系统确认。
4. 在传输记录中查看创建和到期时间，以及每台设备的处理状态。可取消并清理待处理传输，也可清理已处理完的记录。到期的记录和暂存文件由 HA 集成清理。
