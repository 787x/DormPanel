## 已实现

- 课程卡片改为独立原生容器，名称、时间、教室分别测量；窄列以两行名称为主，辅助字段按宽高隐藏，文本省略且整体裁切，原文保留在无障碍描述和原详情。
- 时间比例从 2 降至 0.8dp/min，100 分钟约 80dp；仅实际重叠才聚合。短课程视觉区间保留实际时间，列的触摸补偿不扩大视觉区间。六色有限色板按 sourceId / seriesId 稳定分配，深浅色分别配深色/浅色背景和相反文字。
- 横屏合并导航与管理操作，减少日期标题高度；离线状态放入周范围。今天/周末底色、静态当前时间线、日期调整和课程修改标记。不引入周期刷新。
