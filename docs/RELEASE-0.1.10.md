# DormPanel Android v0.1.10

Android Stable Release：X08E 0.1.10（code 13）、Phone 0.1.9（code 11）。minSdk 28，targetSdk 保持 37。

## X08E
- 可配置的经典列表、实际时间、按节次课表布局。
- 可选课程配色与信息层级优化。
- 可选左右横划切换周次。
- 共享课表管理与目录选择体验改进。

## Phone
- 五天/七天周视图及两种时间轴，更清楚的节次时间与课程信息。
- 日视图/周视图可选横划导航。
- 课程管理及多时段统一编辑。
- 今日课程紧凑版、宽版桌面小部件。
- 独立小部件名称、明日课程开关与刷新可靠性改进。
- 共享课表管理与目录选择体验改进。

## 升级与组件
使用正式签名 APK 原位升级，保留数据；不要卸载重装。本轮不修改 Room schema、Sync v2/v3 协议格式，也不会自动执行 v2→v3 数据迁移。
X08E、Phone、HA、FPK 版本各自独立。本次没有新的 HA ZIP 或 FPK；HA Integration 0.1.2 和 fnOS FPK 0.8.1 沿用已有发布。

## 验证范围
复用 PR62–66 既有定向回归与实装记录，本轮补正式 APK 身份、批准签名、SDK、非 debuggable、ZIP 完整性及冻结文件 SHA-256 核验。
本轮未获日用设备安装授权，未执行 X08E / Phone 正式包原位升级、启动和正式 MIUI 小部件检查；历史隔离包验收不等同于本轮正式包实机 PASS，保留此验证风险。
